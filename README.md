# blackrooster

This repository was converted to an Angular application in the `angular-setup` branch.

How to run locally:

1. Install Node.js (LTS recommended).
2. Run `npm ci` to install dependencies.
3. Run `npm start` to run the dev server.
4. Run `npm run build` to produce a production build in `dist/blackrooster`.

Deploy to Netlify:

- Build command: `npm ci && npm run build`
- Publish directory: `dist/blackrooster`
